# Typography

Playfair Display regular and italic variable fonts are self-hosted, unmodified,
from the Google Fonts `ofl/playfairdisplay` directory:
https://github.com/google/fonts/tree/main/ofl/playfairdisplay

See `PlayfairDisplay-OFL.txt` for the SIL Open Font License and copyright notice.

Body typography uses `"Helvetica Neue", Helvetica, Arial, sans-serif` in that order.
Helvetica Neue is used when installed on the reader's device; the project does
not redistribute a proprietary Helvetica Neue font. Helvetica is installed on
the current local preview machine. A licensed Helvetica Neue webfont can be
added later to provide the exact face consistently across devices.
